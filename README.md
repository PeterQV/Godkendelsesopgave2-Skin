# Skin – Godkendelsesopgave 2
En mobilapp, der forbinder kunder med tattoo artists, barbers og frisører.
Kunder kan finde et studie, der matcher deres stil, se portefølje og anmeldelser, booke en ledig tid og sende en forespørgsel med billede direkte i appen uden at skulle browse Instagram eller Google Maps.

## Kør projektet
1. Installér pakker: `npm install`
2. Opret et Firebase-projekt med en Realtime Database (Belgium, test mode).
3. Kopiér `.env.example` til `.env.local` og indsæt dine egne Firebase-værdier. Filen er i `.gitignore` og ligger derfor ikke på GitHub.
4. Start appen: `npx expo start -c`
